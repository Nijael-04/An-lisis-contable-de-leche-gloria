# Presentación EC3 de Leche Gloria

Descomprime el archivo y abre index.html en el navegador. La presentación funciona sin conexión. Los enlaces a las fuentes requieren internet.

La exposición recorre ocho diapositivas en cinco bloques. El índice identifica qué pregunta responde cada integrante. El orden conserva el reparto de la versión anterior. Para editar los nombres, cambia la lista presenters al comienzo de presentacion.js.

- Usa las flechas izquierda y derecha para navegar. Cada avance resalta las cifras que sustentan la respuesta antes de seguir a la siguiente diapositiva.
- El panel de la derecha muestra la conclusión de cada tabla y la pregunta que sigue. Al terminar un bloque, el botón de avance indica a quién se le da el pase.
- Pulsa N o Guion para ver lo que se dice en voz alta. La sección resaltada corresponde al momento que se está mostrando en la diapositiva. El guion incluye las frases que anuncian el pase.
- Pulsa T para abrir la tabla completa de esa diapositiva y F para activar o desactivar la pantalla completa. Esc cierra un cuadro abierto.
- Los importes de las tablas proyectadas están en millones de soles, con las excepciones indicadas en los encabezados. Las tablas completas reproducen los importes del informe en miles de soles.
- La impresión del navegador muestra las diapositivas principales.

Para publicar en GitHub Pages, sube index.html, presentacion.css y presentacion.js a la raíz del repositorio. En Settings → Pages, selecciona Deploy from a branch, main y / (root).
